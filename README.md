# Legacy's Simple PDFs

A simple free pdf editor that just views pdfs and has a few tricks up its sleeve. It should be built on ReactJS and compiled for Android phones. It has 6 features:
1. Save copy
2. Share
3. Show/hide tools
4. Zoom in/out
5. Select-highlight (click select button and click somewhere on the page then click somewhere else on the current page and then the text between the two points is selected, one can then copy that text or highlight it or remove highlights -- after second click the select button is no longer active)*
6. (When select is off), double clicking on a paragraph opens a simple popup editor for the current paragraph on the current page that allows the user to edit the text and save the changes*

* these edits are saved instantly over the same file
